# Revision circuit

A loop I can run in an evening without opening a paper I will not
finish.

1. Read [what the exam asks](01-what-the-exam-asks.md) and the
   [formula card](12-formula-card.md).
2. Open `problem-01-press-then-notice.txt` and mark the hinge on
   paper before the laptop does.
3. Run `examples/labs/00_split_and_count.py` and check the count
   matches what I circled.
4. Run `01_feature_table.py` on the same file. Find `shall` and
   `I have found` with my eyes first.
5. Run `02_ncd_by_hand.py`. Copy `C(x), C(y), C(xy)` onto the formula
   card and finish the arithmetic.
6. Run `03_score_one.py` and `04_score_corpus.py`. Write the macro-F1
   on the [live results](14-live-results.md) page if it moved.
7. Run `05_calibrate.py`. If the best `t` is not `0.34`, ask why
   before changing the default.
8. Run `06_ablate.py` and `07_topic_confound.py`. The trap files
   should be quieter than the easy files on the function-word
   channel.
9. Run `08_accuracy_trap.py`. Say the never-fire sentence out loud.
10. Run `09_explain_gift.py` and `10_write_reports.py`.
11. Flip three [oral cards](10-oral-cards.md) without looking at the
    answers. If I stall, write a worse sentence and then a better
    one. Do not reread the whole notes.

If I only have forty minutes: steps 2, 5, 8, 9, and one oral card.
