# House voices

Six cartoon registers. They are not real people. They are knobs we
turn so a six-line document has a fold you can hear.

| voice | person | contractions | formal | hedges | typical genre |
| --- | --- | --- | --- | --- | --- |
| **stall** | I | high | none | rare | kiln daybook, dumpling notes |
| **notice** | none | none | shall / must / pursuant | none | fire hall, inspection, phyto |
| **notebook** | we | none | rare | perhaps / approximately / consistent | bellfounders, tuners, clerks |
| **letter** | you / I | some | none | rare | thank-you, seed librarian |
| **minutes** | the chair / it was resolved | none | shall in resolutions | none | harbour committee |
| **chat** | I, fragments | high | none | none | radio rundown, skipper VHF |

## Why these six

They factor the exam vector. Stall versus notice moves *I*,
*contraction*, and *formal* at once. Notebook versus notebook moves
almost nothing. Letter versus notice moves *you* and *formal*. Chat
moves length and vocatives, which we **do not** put in the L1 — and
that is why chat still jitters, because the leftover channels twitch.

## Hard pairs are the same voice twice

`problem-13` through `problem-18` are two specialists writing the same
notebook. Gold says there *is* a hinge in the middle. The detector
should not see it. If your oral claims "our system finds close
same-register pairs," you are not talking about this revision.

## Collage is not realistic

`problem-23` is four voices in four lines. Nobody writes a letter that
way. It exists so you can watch three folds fire in a row and so you
can say, out loud, that a teaching collage is not a claim about
natural text.
