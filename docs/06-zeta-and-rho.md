# ζ as silence, ρ as blade width

I am not allowed to treat defaults as nature. They are knobs
with jobs.

## The prior is the first silence

Without a prior, a four-paragraph Skiff file has a tiny `s_f`.
A 0.02 twitch in *I* becomes a 5-sigma event and the relative
peak rule marks it. The prior is the claim that **a quiet
room cannot invent a border**. ζ then asks whether the
scaled jump is still loud.

If I drop ζ to 0.3, traps start to vote on *n_words* and
*the*. If I raise it to 2.5, hard same-topic house changes
lose the quieter maps (Roll versus Brine) and fall under `k`.

## ρ — relative peak

ρ says a channel may mark more than one hinge if both jumps
are close to its own peak. ABA needs this. Skiff → Roll →
Skiff should let *I* mark both seams. If ρ = 1.0, only the
single loudest hinge of *I* marks, and the return is mute.

If ρ = 0.3, every modest echo of the peak also marks, and
controls pick up scatter.

`0.70` is a blade I can draw: "near the peak, not the peak
alone, not the whole ridge".

## k — the bundle

`k = 1` is a peak-picker in disguise. `k = 2` is a pair I
will not defend as a dialect border. `k = 3` is the smallest
bundle I will say out loud. `k = 5` is a coward on a
four-unit hard file.

## Holdout discipline

I am allowed to stare at 01–03, 05–09, 11–15, 17–21, 23–25,
27–29 while I pick ζ, ρ, k. I am not allowed to stare at
**04, 10, 16, 22, 26, 30** until I score them once and write
the number down. That is the only reason those codes exist.
