# ABA and the return

A two-means story wants one cut. Real gift-authorship stories
are often a guest in the middle: A, then B, then A again.
Document 29 is that file: Skiff on the weir, Roll in the oast
minutes, Skiff in the withy bed.

## What a saw does

Global binary segmentation finds the loudest mean shift,
usually the first Skiff→Roll, then has to recurse with a
harsher penalty to find the return. That is a coherent oral
(kerf-shaped). It is not this lab.

## What a bundle does

Hinge 1 (Skiff→Roll) should pile *I* down, contractions
down, *the* / *was* / *shall* up. Hinge 3 (Roll→Skiff)
should pile the same maps in reverse. ρ < 1 is what lets
both seams mark even if one jump is quieter. Hinges 0, 2, 4
are inside a house and should stay unmarked.

## What I will not call success

Firing the first seam and missing the return. That is a
peak-picker. Firing every hinge because Roll is "formal"
and I blended it into one axis. That is a cowardly distance.

## Collage

Document 30 is four houses, three seams, four topics. If the
bundle is real, votes should sit on 0, 1, 2 and nowhere
else. There is nowhere else. That file is a holdout so I
cannot polish ζ until the collage is cosmetic.
