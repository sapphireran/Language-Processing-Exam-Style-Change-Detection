# Cheatsheet

- Task: binary author-change at each paragraph hinge. Output length
  `n-1`.
- Intrinsic: no external author gallery.
- Easy data leaks topic. Hard data holds topic still. Trap = same
  voice, new topics.
- NCD: `(C(xy)-min(C(x),C(y)))/max(C(x),C(y))`. zlib ≈ Kolmogorov
  from above.
- Short text starves zlib. Add char 3-grams.
- Function words are the topic-light channel.
- Quoin decision: register + shape + function + char. NCD is printed
  and often silent on short original prose.
- Bit if `Q ≥ 0.72` or `Q` is the file's peak by `≥ 0.08`, and
  `Q ≥ 0.40`.
- Never-fire accuracy is high. Quote F1. All-zero/all-zero ⇒ F1=1.
- Macro = mean of per-doc F1. Micro = pooled hinges.
- Gift authorship: mark the insert, not the rest of the student.
- Author return: two hinges, not a third name.
- A hinge is a flag. Not a verdict. Not a name.
- `python -m quoin score examples/corpus`
