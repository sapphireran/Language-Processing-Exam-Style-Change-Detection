# Cheatsheet

- **Task:** mark paragraph hinges where the author changes. Intrinsic. Not attribution.
- **Thesis:** a document is a walk; a change is a change-point; I saw it.
- **Vector:** closed-class + shape. Saw uses a short fingerprint (person, deontics, contractions, hedges). No nouns.
- **Score:** `||μL − μR|| · √(k(n−k)/n)`. First τ=0.22, recurse τ'=0.40, adjacent floor δ=0.40.
- **Metric:** macro-F1 on change and same. Accuracy is the never-fire liar.
- **Bands:** easy = topic+house; medium = house; hard = close houses; trap = topic only; return = ABA.
- **Holdout:** 04, 10, 15, 19, 23, 26, 28.
- **Live miss:** doc 27 last hinge, Seminar → Pocket.
- **Authors ≠ 1+cuts** on returns.
- **Ethics:** original text, no accusations, no scraped inboxes.
- **NCD:** nice story, saturates on short paragraphs, not the saw.
