# Why one feature is a wrinkle

Suppose Flint writes `Bags filled: 3 at 25 kg` and then, still
Flint, `Yield 86 kg`. Digit rate twitches. A blended L2 can
call that a change. A peak-picker on a single register axis
can call it the loudest hinge in a quiet file. An isogloss
atlas calls it a wrinkle: **one map moved**.

A house change moves several maps at once.

- Skiff → Roll: *I* falls, contractions fall, *the* rises,
  *was* rises, *shall* rises. That is five marks if the
  paragraphs are long enough.
- Twine → Vellum: *you* falls, hedges fall, questions fall,
  *we* rises, *however* rises. Bundle.
- Flint → Brine: digits fall, *shall* rises, *n_words* rises.
  Bundle, even on the same lime kiln.

## The coincidence I do not trust

Two marks can be a real border that I under-wrote. They can
also be *n_words* plus *the* drifting because one paragraph
is a list. I set `k=3` so I have to defend a miss as "I
under-wrote the house" rather than "my threshold is shy".

If I need `k=2` to catch Skiff → Twine, I have not separated
those houses on the page. The fix is the prose, not the
constant.

## Peak-relative marks

A channel that never moves should not vote. A channel that
moves once, hard, should vote at that hinge and not at the
noise floor. So a mark requires both:

- an absolute floor `ζ` (silence is not a dialect border),
- a relative floor `ρ · peak_f` (only near that channel's
  own loudest jump).

That second clause is the atlas move: each feature draws its
own isogloss, then I ask where the lines pile up.
