# Closed-class maps

A content word is a vote for a topic. A function word is a vote
for a hand. I only count the second.

## Channels

| channel | what it hears |
| --- | --- |
| `i_rate` | I, me, my, mine, and the contracted forms |
| `we_rate` | we, us, our |
| `you_rate` | you, your |
| `one_rate` | generic *one* (Vellum) |
| `contraction_rate` | any token with an apostrophe |
| `deontic_rate` | shall, must, ought, required, may, … |
| `hedge_rate` | maybe, perhaps, sort of, a bit, … |
| `formal_rate` | however, therefore, thus, moreover |
| `oral_rate` | so, then, anyway |
| `past_copula_rate` | was, were (Roll's minutes) |
| `the_rate` | article stacking |
| `digit_rate` | numerals (Flint's card) |
| `mean_word_len` | shape, not a noun |
| `n_words` | how long the hand stays in a unit |
| `question_rate` | Twine asks; Roll does not |

Digits are a closed habit on this bank: Flint writes `12 kn`.
Skiff writes *light*. I am allowed to count the numeral because
it is how the hand *moves*, not what the hand is *about*.

## Houses as maps

- **Skiff:** I, contractions, oral *so* / *then*.
- **Roll:** *the*, *was* / *were*, some *shall*, no apostrophes.
- **Twine:** you, hedges, contractions, questions.
- **Vellum:** we / one, formal connectives, long units.
- **Flint:** digits, tiny units, no person.
- **Brine:** *shall* / *must*, no *was-resolved*, no person.

Roll and Brine are the pair that can fool a blended distance.
Both are deontic and third-person. The bundle still has a
chance: Roll pays *was*, Brine does not; Brine pays more
*shall*; Roll stacks *the*.

## What I refuse

I refuse *eel*, *hop*, *kiln*, *peat*, *sett*, *hurdle*. If a
model needs those words to find a hinge, it is doing topic
change detection and calling it style. That is the easy-band
cheat. It dies on hard, and it dies on my traps.
