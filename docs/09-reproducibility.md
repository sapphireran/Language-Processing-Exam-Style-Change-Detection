# 9. Reproducibility of the toy corpus

Official PAN datasets are Reddit-derived and are **not** in this
repository. Everything under `examples/data/` is generated by
`scd.generate` with a fixed seed so the notes and the files cannot
drift apart.

## Personas

Four exaggerated writers. Habits are intentionally louder than
real stylometry so a linear model can demonstrate the difficulty
ladder on a handful of documents.

| ID | Register | Contractions | Person | Length | Punctuation |
|----|----------|--------------|--------|--------|-------------|
| avery | formal academic | never | almost never 1st | long | commas, `;` rare `!` |
| blake | casual internet | often | 1st and 2nd | short | `!`, commas optional |
| casey | technical procedural | rare | none | medium | parentheses, digits |
| drew | narrative past | rare | 1st plural / none | medium | commas, quotes |

Each persona has its own **sentence templates** and a small
**function-word bias** (Avery likes *however* / *therefore*;
Blake likes *just* / *really*; Casey likes *then* / *via*).

## Topics

Easy documents *change topic when they change author*. Topic pools:

- baking / kitchen technique
- delayed trains and tickets
- weekend hiking
- debugging a flaky test

Medium documents stay in one **domain** (all coffee, or all city
transport) but still allow slightly different subtopics.

Hard documents lock a **single topic sentence bank** and only
swap the persona's closed-class habits, length, and punctuation.
Content nouns overlap on purpose.

## Document construction

```
choose band
choose author sequence, e.g. A A B B A
for each slot:
    sample a sentence from (persona, topic_allowed_for_band)
write one sentence per line
write changes[i] = 1 iff author[i] != author[i+1]
```

Author sequences always include at least one switch when
`authors >= 2`, and no switch when `authors == 1`. A few
single-author documents are included in each band so the
majority class is not only "the two sentences of the same
person in a mixed doc".

## Seeds

`scd.generate.DEFAULT_SEED = 20260316`

`examples/data/` was written by:

```
python -m scd.generate --out examples/data --seed 20260316
```

Re-running that command must be a no-op (same bytes) if you have
not changed the generator. `tests/test_generate.py` checks that
the committed files match a fresh generate() call.

If you change templates, bump the seed in the notes *and* regenerate
*and* re-read the worked example. Problem-1 in the easy band is
pinned in `scd.generate.PINNED_EASY_PROBLEM_1` so the souffle/pizza
walk-through cannot be overwritten by a template tweak.

## Counts

The committed toy set is small on purpose (exam notes, not a
benchmark):

| Band | Documents | Notes |
|------|-----------|-------|
| easy | 12 | Topic jumps with authors |
| medium | 12 | One domain per document |
| hard | 12 | One topic bank per document |

That is enough to train a regularised logistic model and to show
the 3×3 train/test pattern. It is **not** enough to claim a new
SOTA. Say that in any write-up that uses these numbers.

## What is not reproducible here

- Official shared-task scores
- Transformer fine-tunes
- Human inter-annotator agreement on "style"

If you want those, go to the public PAN pages and the published
overview papers. This repo stops at a teaching corpus.
