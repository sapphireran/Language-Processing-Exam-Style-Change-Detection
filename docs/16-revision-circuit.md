# Revision circuit

A loop I can finish, not a syllabus I will not.

## Day pass (about an hour)

1. Read the cheat sheet out loud.
2. Inspect document 19. Name the channels before the command.
3. Inspect a trap (25 or 27). Name why it must stay quiet.
4. Score the bank. Write the liar table into `14`.
5. Score the holdout once. Do not retune.

## Oral pass

- Six cards from `10-oral-cards.md`.
- One near-pair speech (Roll / Brine).
- One ethics sentence.

## Written pass

- Answers 1–5 in `11` in twenty-five minutes, no notes.
- Formula card from a blank page.

## If a number is ugly

Do not add a noun. Do not drop `k` to 1. Either rewrite a
house so the maps are true, or write the miss in the error
taxonomy and take it to the oral as a known scar.
