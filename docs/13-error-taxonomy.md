# Error taxonomy

I want names for misses, not vibes.

## False change (type I)

The saw marks a hinge inside one house. On this bank I currently
have **none**. If one appears after I edit a paragraph, it will
almost certainly be:

- a possessive counted as a contraction (already patched),
- a question mark in one Bench paragraph and not the next,
- a two-paragraph recurse that reused the first-cut penalty.

## False same (type II)

The saw misses a real house change.

**Diluted return.** ABA makes each global split mixed. Adjacent
floor is the patch. Document 24 is the example I recovered this
way.

**Shared person.** Seminar (`we`) and Pocket (`I`) are both
first-person-ish. Document 27's last hinge is the live miss.
Raising sensitivity to catch it would invent a type I on document
13.

**Too-similar formality.** Caliper vs Statute (document 19) could
have been this; on the current bank the *shall* rate saves it.

## Topic costume (looks like type I if I cheat)

A content model fires on documents 20–23. That is not a kerf
error. It is a feature error. If I ever add nouns to the saw I
will have turned type-correct quiet files into type I.

## Length costume

A one-sentence paragraph next to a long one moves `mean_sent`
even inside a house. I down-weighted that feature after it drowned
the fingerprint. If I see a control start to cut, I look here
first.

## How I will talk about the live miss

> One false same, zero false change. The miss is Seminar into
> Pocket on a four-house well. I know how to catch it. I also
> know what else that catch would break. I prefer the honest miss.
