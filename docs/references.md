# References

Public pointers for the oral, not a reading list you must finish.

- PAN / CLEF multi-author writing style analysis task pages (shared-task *definition* of sentence-level `changes` arrays). This repo does not include those datasets.
- Burrows, J. (2002). "Delta": a measure of stylistic difference and a guide to likely authorship. *Literary and Linguistic Computing*.
- Holmes, D. I. — surveys of stylometry and the closed-class tradition.
- Juola, P. — authorship attribution tutorials; useful for intrinsic vs extrinsic wording.
- Argamon, S. & Koppel, M. — function words and register.

For formulae used in code, the implementations in `src/hingemark/` are the spec. If a note and the code disagree, trust the code and then fix the note.
