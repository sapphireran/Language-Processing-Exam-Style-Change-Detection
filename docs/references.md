# References (personal reading list)

These are pointers for exam revision. The repository does not
redistribute any of the papers or any PAN corpora.

- Burrows, J. (2002). ‘Delta’: a measure of stylistic difference
  and a guide to likely authorship. *Literary and Linguistic
  Computing*, 17(3), 267–287.
- Stamatatos, E. (2009). A survey of modern authorship attribution
  methods. *JASIST*, 60(3), 538–556.
- PAN / CLEF multi-author writing style analysis task pages
  (2022–2026), including the sentence-level 2025 edition and the
  Easy / Medium / Hard construction.
- Zangerle, E. et al., overviews of the PAN multi-author writing
  style analysis tasks (year-specific overview papers).
- Juola, P. (2008). *Authorship Attribution*. Foundations and
  Trends in Information Retrieval.

Teaching data in `examples/corpus` is original prose written for
this repository. It is not derived from Reddit dumps or from
shared-task problem files.
