# Oral cards

Short answers. If you wander, you are not using the card.

**What is a style change?**
A fold in register — closed-class habits — not a new topic.

**Give me a feature.**
First-person rate, contraction rate, *shall*/*must* rate. I can count
them on six lines.

**Why not accuracy?**
Most boundaries are seams. Never-fire is about 0.77 accurate on this
folder and finds no folds.

**Why not character n-grams?**
On six lines they are content. They fire when the stall voice changes
the subject.

**Why did you miss the bellfounders?**
Same notebook: *we*, hedges, no contractions. Named miss
`same_register_miss`. The gold hinge is identity, not register.

**How do you set a threshold?**
Peak above 0.30, sure-fold above 0.45, refuse if register L1 < 0.18.
Picked on this folder; I would refit on a real training split.

**What is the return trap?**
`problem-22`: two authors, two folds, naive `1+sum` is 3. A segment
is not an author.

**Intrinsic or extrinsic?**
Intrinsic. No gallery. Intra-document Delta is not corpus Delta.

**Limitation you actually observed.**
`chat_jitter` on problem-21. Short wire units false-alarm. I would
not deploy this on Slack dumps without a different unit and a
vocative brake.

**Ethics in one sentence.**
I will not claim a fold is a named person, and I will not run this on
private messages I was not given.
