# Ethics, in the tone the oral actually wants

Style-change tools are used on exam scripts, leaked documents,
ransom notes, and group chats. The method in this folder is a
cartoon on twenty-six made-up sentences. It does not identify a
human being.

## Do not do these things

- Claim a fold is *a named person*. A fold is a register jump.
- Run the detector on private messages you were not given for this
  purpose. "I could" is not consent.
- Treat a miss on a same-register pair as proof of single authorship.
  Two bellfounders are still two people.
- Treat a hit on a gift abstract as proof of misconduct. Supervisors
  rewrite abstracts for many reasons, including kindness.
- Hide the chat-jitter false alarms when you talk about "accuracy."

## Do these things

- Say the system is intrinsic and short-span and closed-class.
- Name the errors.
- Keep the teaching documents original so you are not
  redistributing someone else's exam or someone else's mail.
- If you ever moved this method near real people, add a human in the
  loop and a written purpose limit.

The gift-authorship document exists so you can *practise marking a
hinge*, not so you can accuse a classmate.
