# Annotation: single-10 lighthouse

Gold: `[0, 0, 0, 0, 0]` — one keeper, six paragraphs.

This is the accuracy trap. Every paragraph has `I`, the lamp, the
gallery door, the crane, the boat that may not run. Cadence shifts
(a yacht anecdote, a dream about kettle water) are still the same
person thinking at two in the morning.

A pairwise detector that z-scores features *inside* this document
will invent an outlier. The lab detector uses raw formality and an
absolute threshold instead, so a quiet page can stay quiet.

If this file ever starts predicting a change, look at the first
pair: P1 is observational, P2 is interior. That is a mood change,
not an author change. Write that sentence in an error analysis.
