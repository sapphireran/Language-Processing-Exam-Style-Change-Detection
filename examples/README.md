# Examples

- `corpus/` — original teaching documents in PAN-shaped files
- `walkthroughs/` — pair-by-pair readings that quote live scores
- `reports/` — HTML generated by `python -m seamtrace report`

Scripts that belong to the lab, not to a shared task:

```
PYTHONPATH=src python3 examples/print_feature_table.py examples/corpus/problem-14-two-bakers.txt
PYTHONPATH=src python3 examples/topic_vs_register.py
PYTHONPATH=src python3 examples/never_fire_demo.py
```

Walkthroughs are rewritten by `scripts/write_walkthroughs.py` after
you change a threshold, so spoken numbers stay honest.
