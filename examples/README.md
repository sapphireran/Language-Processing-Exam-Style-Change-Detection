# Examples

- `corpus/` — 26 original sentence-level documents plus gold files.
- `voices.md` — house-style cards used to write those documents.
- `labs/` — short scripts you can run in order during revision.
- `walkthroughs/` — live hinge tables for the spotlight files (regenerated by `scripts/write_walkthroughs.py`).
- `reports/` — optional HTML dumps from `hingemark report`.

Start here:

```bash
PYTHONPATH=src python3 -m hingemark explain examples/corpus/problem-13-two-mycologists.txt
PYTHONPATH=src python3 examples/labs/run_all.py
```
