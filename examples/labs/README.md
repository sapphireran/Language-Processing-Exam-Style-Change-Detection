# Labs

Short scripts I can run before an oral. They are not a test suite.

```bash
cd examples/labs && python3 run_all.py
# or one at a time
cd examples/labs && python3 05_hand_bundle.py
```

| script | job |
| --- | --- |
| `01_inspect_hard.py` | document 19 table |
| `02_trap_vs_easy.py` | 07 fires, 25 stays quiet |
| `03_votes_not_distance.py` | L2 can twitch; votes should not |
| `04_never_fire_liar.py` | whole-bank liar table |
| `05_hand_bundle.py` | name the marks on 19 |
| `06_aba_return.py` | both seams on 29 |
| `07_house_fingerprint.py` | mean rates per house |
| `08_holdout.py` | 04 / 10 / 16 / 22 / 26 / 30 |
| `09_channel_ablation.py` | drop a family, watch F1 |
| `10_formula_check.py` | two-unit Skiff→Roll must fire |
