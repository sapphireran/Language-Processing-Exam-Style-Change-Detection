# Labs

Run from the repository root with `PYTHONPATH=src`.

| lab | script | look at |
| --- | --- | --- |
| 00 | `00_split_and_count.py` | units and token counts |
| 01 | `01_feature_table.py` | six rates per unit |
| 02 | `02_hinges.py` | adjacent + window scores |
| 03 | `03_cusum.py` | first-person CUSUM picture |
| 04 | `04_score_corpus.py` | full scoreboard |
| 05 | `05_calibrate.py` | a tiny threshold sweep |
| 06 | `06_ablate.py` | drop register vs drop function words |
| 07 | `07_topic_confound.py` | stall control vs a content leak |
| 08 | `08_accuracy_trap.py` | never-fire row |
| 09 | `09_explain_gift.py` | student → supervisor |
| 10 | `10_write_reports.py` | HTML under `examples/reports/` |

`run_all.py` executes 00–10 in order.
